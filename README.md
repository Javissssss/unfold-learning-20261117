# Unfold

面向个人的英语场景练习工作台。以语境中的听、读、表达和回想为主线；题目和自评不是正式英语能力测评，也不保证达到母语水平。

## 打开

在 Windows PowerShell 中进入本目录，运行 `./启动.ps1`，然后在浏览器打开 `http://127.0.0.1:8791/`。保持窗口运行；`Ctrl+C` 停止。Python 3.11 以上，标准库即可，不需要安装项目依赖。不要直接双击 HTML。

## 练习

- 场景库内置 17 个原创虚构场景：原有职场材料，加上日常、社交、旅行、饮食、影视文化、科学、人际关系、观点思辨。可按主题、难度和关键词筛选。每个场景有听力对话、阅读、理解题和表达任务。
- 内置音频由本机预生成的 Kokoro 神经声线分角色合成，**不是真人录音**。可在播放时调整速度；切换浏览器标签或站内页面不会主动暂停。关闭、刷新或在同一标签导航离开页面会结束播放；不同系统的后台策略可能影响播放。模型、制作方式及校验值见 `audio/音频来源.md`。
- 选择「读」时，可先选中一个词或短语，再点「收藏生词」；也能手动填写、补充语境与解释。在「复习 → 生词」查看、编辑、删除或使用 AI 辨析。表达收藏与生词库分开保存。
- 设置中的字号有即时预览，并作用于英文材料；播放速度作用于内置音频。内置音频不能更换声线，浏览器朗读声线仅用于没有预录音频的材料，可先试听。

## 账号、同步与备份

在「设置 → 账号与同步」注册或登录。账号密码至少 10 位；**没有密码找回功能**。创建账号时会复制当前访客记录，保留访客副本；登录已有账号会加载该账号记录。进度、表达、生词、记录、草稿、偏好和 AI 生成材料存入当前服务器的账号，并在浏览器保留副本。服务器版本冲突会暂停同步，先导出副本再选择服务器版本或本机版本；不会自动合并。

**默认服务器只运行在本机，账号数据存储在本机，不等于云端，无法自动跨电脑或手机同步。** 要实现跨设备，所有设备必须访问同一个另外部署的 HTTPS 服务，并为服务端数据配置持久存储、备份及安全管理。本项目未部署云服务，不提供可直接使用的公网地址；仓库本身也不是云数据库。公网部署前需要独立安全审查、受信任的 HTTPS 反向代理、备份和访问策略，不要直接把本机服务或账号数据库暴露到公网。

服务端账号数据库默认位于系统用户数据目录的 `Unfold/accounts.sqlite3`，不存放在项目文件夹；访客记录仍在浏览器。可用 `UNFOLD_DATA_DIR` 指定服务端数据目录。数据库包含学习内容，非端到端加密，设备管理员可读取。清除浏览器缓存、换服务地址或误删服务器数据都可能影响访问；定期通过「设置 → 导出备份」保存 JSON。导入会替换当前记录，先导出；登录状态下该更改会同步。备份不包含 API 密钥、账号密码、录音或自选音频。

## 使用 AI

在「设置 → AI辅助」填写兼容 Chat Completions 的 HTTPS API 根地址、模型名和 API 密钥。根地址通常以 `/v1` 结束，不要加 `/chat/completions`。不同服务商要求的生成长度参数可能不同；可选择 `max_completion_tokens`、`max_tokens` 或不发送。保存配置仅表示参数已配置，不代表真实调用成功；可点击试一次解释。

AI 能生成指定主题和难度的新场景、解释情境表达、反馈英文短写、辨析生词、接续角色文字对话并给出建议。每次请求前显示发送目标和费用提示，并要求确认；结果可能有误，生成的题目应自行核对。文字对话仅留在当前页面期间；没有口语发音评分或语音实时对话。AI 材料不自动附带神经音频；可选择对应本地音频，或手动选择浏览器语音作为备选。

密钥只存服务进程内存，重启服务或登录账号退出后需重填；不写入学习备份、源码或仓库。不要将密钥或公司内部经营、成本、客户资料输入练习内容或 AI 对话。用户填写密钥会通过当前服务发送给所选服务商用于请求；本机服务只绑定回环地址。不要将不可信地址设为 AI 服务。真实模型尚需用户提供可用凭据验证；测试用模拟接口不代表真实服务验证。

## 项目文件

- `app.js` / `styles.css` / `extra.css` / `index.html`：界面与交互。
- `lessons.json` / `catalog.json`：原有和新增虚构教材。
- `audio/`：内置音频及来源说明。
- `server.py` / `accounts.py`：本机服务、AI接口和账号存储。
- `使用说明.md` / `优化复盘.md`：历史版说明和复盘，最新行为以本 README 为准。
