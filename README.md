# Unfold

面向个人的英语场景练习工作台。以语境中的听、读、表达和回想为主线；题目和自评不是正式英语能力测评，也不保证达到母语水平。

## 打开

在 Windows PowerShell 中进入本目录，运行 `./启动.ps1`，然后在浏览器打开 `http://127.0.0.1:8791/`。保持窗口运行；`Ctrl+C` 停止。Python 3.11 以上，标准库即可，不需要安装项目依赖。不要直接双击 HTML。

## 练习

- 场景库内置 **36 个原创虚构场景，覆盖 23 个主题**：职场沟通、项目与会议之外，还有日常生活、社交邀约、旅行、饮食、影视文化、科学证据、人际情绪、观点思辨、新闻、健康、科技隐私、学习记忆、金钱消费、环境习惯、居住、运动、家庭边界、职业取舍、城市公共。可按主题标签、难度和关键词筛选。每个场景都有听力对话、阅读、理解题和表达任务。
- 内置音频由本机预生成的 Kokoro 神经声线分角色合成，**不是真人录音**。每个场景提供两套可选声线（美音 / 英音），同一套内口音一致、男女角色分开配音，不朗读角色名。可在播放时 0.75×—1.15× 调速；切换浏览器标签或站内页面不会主动暂停。关闭、刷新或在同一标签导航离开页面会结束播放；不同系统的后台策略可能影响播放。
- 逐句精听：展开原文后每一句都是可点的播放单元，可单句循环；「跟读模式」会先播一句，再留出与该句等长的时间让你复述，然后自动进入下一句。
- 选择「读」或展开「听」的英文原文时，选中一个词或短语都会浮出同一条工具条：查看释义、收藏生词、朗读。收藏时保存的是整句语境，不含角色名和时码。生词库支持按间隔复习、导出 CSV。表达收藏与生词库分开保存。
- 设置中字号、主题（跟随系统 / 浅色 / 深色）、速度、音量即时生效；字号作用于整个界面与英文材料，不只是正文。

## 快捷键

听力页（不在输入框中时）：`空格` 播放/暂停，`←` / `→` 后退/前进 5 秒，`J` / `K` 下一句 / 上一句，`Esc` 关闭弹窗或退出跟读模式。

## 账号、同步与备份

在「设置 → 账号与同步」注册或登录。账号密码至少 10 位；**没有密码找回功能**。创建账号时会复制当前访客记录，保留访客副本；登录已有账号会加载该账号记录。进度、表达、生词、记录、草稿、偏好和 AI 生成材料存入当前服务器的账号，并在浏览器保留副本。服务器版本冲突会暂停同步，先导出副本再选择服务器版本或本机版本；不会自动合并。

**默认服务器只运行在本机，账号数据存储在本机，不等于云端，无法自动跨电脑或手机同步。** 要实现跨设备，所有设备必须访问同一个另外部署的 HTTPS 服务，并为服务端数据配置持久存储、备份及安全管理。本项目未部署云服务，不提供可直接使用的公网地址；仓库本身也不是云数据库。公网部署前需要独立安全审查、受信任的 HTTPS 反向代理、备份和访问策略，不要直接把本机服务或账号数据库暴露到公网。

服务端账号数据库默认位于系统用户数据目录的 `Unfold/accounts.sqlite3`，不存放在项目文件夹；访客记录仍在浏览器。可用 `UNFOLD_DATA_DIR` 指定服务端数据目录。数据库包含学习内容，非端到端加密，设备管理员可读取。清除浏览器缓存、换服务地址或误删服务器数据都可能影响访问；定期通过「设置 → 导出备份」保存 JSON。导入会替换当前记录，先导出；登录状态下该更改会同步。备份不包含 API 密钥、账号密码、录音或自选音频。

## 使用 AI

在「设置 → AI辅助」填写兼容 Chat Completions 的 HTTPS API 根地址、模型名和 API 密钥。根地址通常以 `/v1` 结束，不要加 `/chat/completions`。不同服务商要求的生成长度参数可能不同；可选择 `max_completion_tokens`、`max_tokens` 或不发送。保存配置仅表示参数已配置，不代表真实调用成功；可点击试一次解释。

AI 能生成指定主题和难度的新场景、解释情境表达、反馈英文短写、辨析生词、接续角色文字对话并给出建议。每次请求前显示发送目标和费用提示，并要求确认；结果可能有误，生成的题目应自行核对。文字对话仅留在当前页面期间；没有口语发音评分或语音实时对话。AI 材料不自动附带神经音频；可选择对应本地音频，或手动选择浏览器语音作为备选。

生词辨析会返回简义、一个新例句、易混点和一个回想问题，用于把词放回语境而不是背孤立对应词。短写反馈只针对表达清晰度与措辞，不评定口音或语言等级。

密钥只存服务进程内存，重启服务或登录账号退出后需重填；不写入学习备份、源码或仓库。不要将密钥或公司内部经营、成本、客户资料输入练习内容或 AI 对话。用户填写密钥会通过当前服务发送给所选服务商用于请求；本机服务只绑定回环地址。不要将不可信地址设为 AI 服务。真实模型尚需用户提供可用凭据验证；测试用模拟接口不代表真实服务验证。

## 音频与质量口径

内置音频为 Kokoro v1.0 fp32 模型本机生成，24 kHz / 16-bit / 单声道 WAV。每一轮发言按标点拆成分句分别合成，短句稍慢、收尾句稍缓，再拼接为一段，因此语调不是一条直线；随后做逐轮响度对齐与母带处理（RBJ biquad 均衡，收掉 100–400 Hz 的闷，抬一点 1.2–3 kHz 的清晰度与齿音区，而不是猛推临场感）。

两套声线各用一种口音：A 为美式（女声 `af_bella`、男声 `am_michael`，第二声部 `af_jessica` / `am_eric`），B 为英式（女声 `bf_isabella`、男声 `bm_george`，第二声部 `bf_emma` / `bm_daniel`），并各自调用对应的美式/英式发音词典，避免“英式嗓音念美式元音”。

上一轮（v7→v8）的客观对比，保留作历史记录，不代表本轮数值：低频浑浊度 14.1 → 2.9，900–2500 Hz 清晰频段能量 0.029 → 0.191，2.5–6 kHz 临场频段 0.027 → 0.119，频谱质心约 775 Hz → 1152 Hz。本轮（v9）重建范围是 36 课 × 2 套声线共 72 个文件，逐句时间轴 72/72 与原文句数对齐。

这仍是 AI 合成，不是真人录音；客观指标改善不等于人耳审音通过，也不等于发音示范。声线、模型来源与逐文件校验值见 `audio/音频来源.md`。

## 已知边界

- 不提供正式英语等级测评或发音评分；口音覆盖仅美音、英音两套，没有澳音、印音等其他变体。
- 训练闭环偏听读：口头复述、短写是选做入口；不能据此证明“四大能力均衡”或“接近母语水平”。
- 真实 AI 质量取决于你配置的服务商与模型；项目未内置凭据，未替你做真实模型联调。
- 跨设备同步需要自建带持久存储与 HTTPS 的服务，默认本机版做不到。

## 项目文件

- `app.js` / `styles.css` / `extra.css` / `index.html`：界面与交互。
- `dict.js`：划词释义用的内置词典。
- `lessons.json` / `catalog.json` / `content.js`：36 个虚构场景（`content.js` 为离线兜底副本）。
- `audio/a`、`audio/b`：两套声线各 36 课、`_preview.wav` 试听样本与 `timings.json` 逐句时间轴。
- `server.py` / `accounts.py`：本机服务、AI 接口和账号存储。
- `使用说明.md` / `优化复盘.md` / `audio/音频来源.md`：使用、复盘与音频制作口径。
